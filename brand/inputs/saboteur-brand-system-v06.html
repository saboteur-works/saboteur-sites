09 — GetWrite mark
GetWrite LOCAL-FIRST WRITING STUDIO — getwrite.io

"Get" at regular weight and mid-grey — prefix, verb, instruction.

11 — System usage rules
Full mark
All three tiers. Hero, landing, print, email.
Minimum width: ~300px.
Reduced mark
Wordmark + Japanese only. Small nav, footers.
Below ~160px wide.
Sub-brand context
SAB/labs and SAB/works replace the primary mark in their own product contexts.
Never stack both sub-brands with the parent.
Product marks
OffBeat-FM and GetWrite marks replace the parent mark within their products. Parent appears in footers and about pages only.
Products are siblings, not children.
Red — universal rule
Marks structure, identity, and active state.
Never body text. Never decorative fill. Never arbitrary accent.
Type roles
Condensed: wordmarks only. Sans: UI and body. Mono: technical labels. Serif: GetWrite editor surface only.
Never mix within the same element.
12 — Do / don't
Do
Use red in the bar as the structural anchor across all marks
Keep FM red in OffBeat-FM regardless of background
Use warm paper surfaces in GetWrite editor — never pure white
Treat products as siblings — same DNA, distinct personalities
Let red frequency vary by product — same token, different tempos
Use #F5F4F0 not #FFFFFF. Warmth is intentional throughout.
Don't
Don't use browser blue for interactive elements — it has no place in this system
Don't use serif type outside the GetWrite editor surface
Don't flood red in GetWrite — it should feel like a marker, not a CTA
Don't use stock photography that reads as "music generally" for OffBeat-FM
Don't use gradients as decoration — surfaces are flat
Don't center marks by default — left-align is primary in all contexts
